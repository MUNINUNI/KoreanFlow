我来为你设计一套完整的方案，将之前所有的开发计划、产品文档和代码规范链接到 Kimi 新建项目中，实现知识沉淀 + 上下文继承 + 团队协作。
一、Kimi 项目功能说明
Kimi 的「项目」功能支持：
•  文件上传：PDF、Word、Markdown、代码文件等
•  知识库关联：将文档作为 Agent 的上下文参考
•  会话继承：新对话自动携带项目知识
•  团队协作：多人共享项目文档

### 步骤 4：配置项目内 Agent（关键）

Kimi 项目支持**自定义 Agent**，可以绑定项目文档作为上下文。

#### 创建「KoreanFlow 开发助手」Agent


项目页面 → 「Agent」→ 「创建 Agent」

**配置**：

```markdown
# 角色
你是 KoreanFlow 项目的专属开发助手，精通 Flutter 开发和韩语学习产品设计。

## 知识来源
回答问题时必须参考以下项目文档：
- @00-INDEX-项目总览
- @01-PRD-产品需求文档  
- @03-CODE-代码规范与模板
- @05-WORKFLOW-开发工作流

## 工作原则
1. **代码生成**：严格遵循 @03-CODE 中的扁平架构和注释规范
2. **功能开发**：对照 @01-PRD 中的功能清单和验收标准
3. **问题诊断**：优先检查 @05-WORKFLOW 中的常见问题
4. **版本管理**：修改后建议更新 @06-CHANGELOG

## 输出格式
- 代码必须包含详细中文注释
- 文件顶部标注用途和修改说明
- 给出文件存放路径
- 如需安装依赖，给出 pubspec.yaml 修改

## 禁止事项
- 不要使用复杂的设计模式（Repository、UseCase等）
- 不要生成无注释的代码
- 不要假设用户有编程基础

方案 B：半自动同步（进阶）
使用 Kimi Code 插件的「项目同步」功能：
VS Code → Kimi Code 面板 → 「绑定项目」→ 选择「KoreanFlow-韩语学习App」

效果：
•  VS Code 中直接 @引用项目文档
•  代码生成时自动参考项目规范
•  保存文件后自动同步到项目知识库
配置：
// .vscode/settings.json 追加
{
    "kimiCode.project.syncEnabled": true,
    "kimiCode.project.id": "koreanflow-2026",
    "kimiCode.project.autoUpload": [
        "lib/**/*.dart",
        "docs/**/*.md"
    ],
    "kimiCode.project.contextFiles": [
        "00-INDEX-项目总览.md",
        "01-PRD-产品需求文档.md",
        "03-CODE-代码规范与模板.md"
