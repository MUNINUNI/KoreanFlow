# KoreanFlow 宝塔面板部署教程（零基础版）

> 适用版本：v2.2.3 部署包 ｜ 预计耗时：30 分钟
> 读完本教程你会得到：一个绑定了自己域名、带 HTTPS 锁标志、手机电脑都能访问的韩语学习网站。

---

## 〇、先搞懂我们要做什么（1 分钟）

这个网站由三部分组成，缺一不可：

| 角色 | 类比 | 在宝塔里对应什么 |
|---|---|---|
| **Node 服务**（网站的“后厨”，做菜的地方） | 厨师 | 用「PM2 管理器」让它一直运行 |
| **MySQL 数据库**（记单词本、学习进度的“账本”） | 账本 | 用宝塔「数据库」创建一个空库 |
| **Nginx 反向代理**（网站的“前台接待”） | 门卫 | 用宝塔「网站」功能把域名指向厨师 |

访问流程：你的浏览器 → 域名（HTTPS）→ Nginx → Node 服务（127.0.0.1:3000）→ MySQL。

---

## 一、准备清单（开始前请打勾）

- [ ] 一台已安装宝塔面板的 Linux 云服务器（1 核 2G 起步，CentOS / Ubuntu / Debian 均可）
- [ ] 能登录宝塔面板后台（一般是 `http://服务器IP:8888/随机入口`）
- [ ] 一个域名，并已把 **A 记录解析到服务器 IP**（在买域名的平台操作，如阿里云/腾讯云控制台）
  - 没有域名也能先用 IP 访问，但**录音跟读功能会失效**（浏览器规定只有 HTTPS 才能用麦克风），强烈建议配域名
- [ ] 已下载部署包 `KoreanFlow-v2.2.3-宝塔部署包.zip`

---

## 二、安装三个必备软件（约 10 分钟）

1. 登录宝塔面板，点击左侧 **「软件商店」**。
2. 搜索并安装以下三个（已装过就跳过）：
   - **Nginx**（任意 1.2x 版本）—— 一般在装宝塔时已装
   - **MySQL**（5.7 或 8.0 均可，v2.2.3 起全兼容）—— 安装时若提示设置 root 密码，记在小本本上（本教程用不到 root，但别丢）
   - **PM2 管理器** —— 搜索 “PM2”，安装官方「PM2 管理器」。它会自动帮你装好 Node.js
3. 装完后打开「PM2 管理器」→「Node 版本」，确认列表里有 **Node 20 或以上**，没有就点安装一个，并设为默认。

> ⚠️ MySQL 安装需要几分钟，去倒杯水。

---

## 三、创建数据库（2 分钟）

1. 宝塔左侧 **「数据库」** → **「添加数据库」**：
   - 数据库名：`koreanflow`
   - 用户名：`koreanflow`（默认同名即可）
   - 密码：点 **「随机密码」**，然后**立刻复制保存**（下一步要用）
   - 访问权限：保持 **「本地服务器（127.0.0.1）」**，更安全
2. 点提交。**不需要**手动建表 —— 网站第一次启动时会自动建好 9 张表并灌入内置词库。

---

## 四、上传部署包并解压（3 分钟）

1. 宝塔左侧 **「文件」** → 进入 `/www/wwwroot/` 目录。
2. 点 **「新建 → 目录」**，名字填 `koreanflow`。
3. 进入 `koreanflow` 目录，点 **「上传」**，把部署包 zip 传上去。
4. 上传完成后，在文件列表里右键 zip → **「解压」**，解压到当前目录。
5. 解压后确认目录结构是这样的（关键看有没有 `dist/boot.js`）：

```
/www/wwwroot/koreanflow/
├── dist/
│   ├── boot.js          ← 网站主程序（后厨本体）
│   └── public/          ← 网页文件 + 510 条发音音频
├── ecosystem.config.js  ← PM2 配置文件
├── .env 配置模板.txt     ← 待会儿要用的配置模板
└── 宝塔面板部署指南.md
```

> 如果解压出来多套了一层文件夹，把里面的内容**剪切**到 `/www/wwwroot/koreanflow/` 根下。

---

## 五、填写配置文件 .env（最关键的一步，2 分钟）

`.env` 是网站的“钥匙串”，告诉它数据库密码是多少。

1. 在 `/www/wwwroot/koreanflow/` 目录里，点 **「新建 → 空白文件」**，文件名**必须**叫 `.env`（注意开头有个点）。
2. 双击打开 `.env`，把 `.env 配置模板.txt` 里的内容粘贴进去，按注释改三处：

```bash
# 把「你的数据库密码」替换成第三步记下的密码，其余不动
DATABASE_URL=mysql://koreanflow:你的数据库密码@127.0.0.1:3306/koreanflow

# 自建站点固定填这个
APP_ID=self-hosted

# 随便敲一串够长的随机字符（当密码用，别人猜不到即可）
APP_SECRET=请换成一串30位以上的随机字符

# 下面两行保持原样
NODE_ENV=production
PORT=3000
```

3. 保存。

> ❗ 三个变量一个都不能少，少了网站会启动失败。
> ❗ 密码里如果含 `@ # : /` 等特殊符号，建议回第三步把数据库密码改成“字母+数字”组合，避免连接串解析出错。

---

## 六、用 PM2 让网站跑起来（3 分钟）

1. 宝塔左侧 **「软件商店」→ 找到「PM2 管理器」→「设置」**。
2. 切到 **「项目管理」→「添加项目」**：
   - 项目名称：`koreanflow`
   - 运行目录：`/www/wwwroot/koreanflow`
   - 启动文件：`dist/boot.js`
   - Node 版本：选 20 或更高
   - 端口：留空（程序自己会读 .env 里的 3000）
3. 提交后等几秒，项目状态变成 **🟢 运行中**。
4. **验证后端活着**：点该项目的「日志」，看到 `Server running on http://localhost:3000/` 和 `[autoboot] 数据库表结构就绪` 两行，说明网站和数据库都通了。
   - 如果看到 `[autoboot] 数据库初始化失败` → .env 里数据库密码不对，回第五步检查。
   - 如果项目起不来/一直重启 → 看错误日志，九成是 .env 没建或变量名打错。

> 此刻网站已经在服务器内部的 3000 端口运行了，但外网还访问不到 —— 接下来请“前台接待”Nginx 出场。

---

## 七、绑定域名 + 反向代理（3 分钟）

1. 宝塔左侧 **「网站」→「添加站点」**：
   - 域名：填你的域名（如 `korean.example.com`）
   - 根目录：默认即可（用不到，但别删）
   - PHP 版本：选 **「纯静态」**
2. 提交后，点该站点的 **「设置」→「反向代理」→「添加反向代理」**：
   - 代理名称：`koreanflow`
   - 目标 URL：`http://127.0.0.1:3000`
   - 发送域名：保持 `$host`
3. 保存后点该条代理的 **「配置文件」**，在 `location / { ... }` 的**大括号外、server 大括号内**补一行（放宽上传大小，方便导入语料）：

```nginx
client_max_body_size 60m;
```

4. 保存。现在用浏览器打开 `http://你的域名`，应该已经能看到网站首页了！

---

## 八、开启 HTTPS 小锁（录音功能的生命线，2 分钟）

1. 站点 **「设置」→「SSL」→「Let's Encrypt」**。
2. 勾选你的域名 → 点 **「申请」**（宝塔自动完成验证）。
3. 申请成功后，打开右上角 **「强制 HTTPS」** 开关。
4. 浏览器访问 `https://你的域名`，地址栏出现 🔒 即成功。

> 申请失败 99% 是因为域名解析没生效。在电脑 cmd/终端执行 `ping 你的域名`，显示的 IP 必须是服务器 IP。

---

## 九、完工验证清单

| 检查项 | 怎么看 |
|---|---|
| 首页能打开 | `https://你的域名` 显示学习总览页 |
| 后端接口通 | 访问 `https://你的域名/api/trpc/ping`，返回一串 JSON |
| 数据库通 | 进「用户中心」能看到统计数字（而不是离线提示） |
| 发音正常 | 单词学习页点 🔊 有韩语人声（510 条内置音频，任何设备一致） |
| 录音可用 | 发音练习页点录音，浏览器弹权限请求且能录（必须 HTTPS） |
| 子路由不 404 | 直接访问 `https://你的域名/corpus` 能打开语料中心 |

全部打勾，🎉 部署完成！把网址发到手机，Safari/Chrome 里“添加到主屏幕”，就是一个韩语学习 App。

---

## 十、以后怎么更新网站

1. 找 Kimi 拿新版部署包（或在有 Node 20+ 的电脑上：源码目录执行 `npm install && npm run build` 得到 `dist/`）。
2. 宝塔「文件」进入 `/www/wwwroot/koreanflow/`，用新 `dist/` **整个替换**旧的。
3. PM2 管理器里点该项目的 **「重启」**。完事。

> 数据库不用动 —— 每次启动自动对比表结构，缺表建表、缺列补列。

## 十一、常见问题急救箱

| 症状 | 病因 | 药方 |
|---|---|---|
| 打开域名显示 502 | Node 服务没跑 | PM2 管理器看项目状态，查日志；八成是 .env 问题 |
| 页面能开但提示“离线模式”，学习数据不保存 | 数据库没连上 | 核对 .env 的密码；宝塔「数据库」确认库存在 |
| 录音按钮没反应 | 没用 HTTPS | 回第八步开 SSL；iOS 还要确认用的是 Safari/Chrome |
| PM2 添加项目后一直“重启中” | Node 版本太低 | PM2 管理器里把项目 Node 版本切到 20+ |
| 申请 SSL 失败 | 域名没解析 / 80 端口没放行 | 检查 DNS 解析；宝塔「安全」和云服务商安全组都要放行 80、443 |
| 改了 .env 没生效 | 没重启 | PM2 里「重启」项目 |
| 日志报 `ER_PARSE_ERROR`、`(now())` 语法错误 | MySQL 5.7 不认识新版建表语法 | 换用 **v2.2.3 及以上**部署包（已做全版本兼容），替换 dist 后重启 |
