KoreanFlow 韩之语 · 本地预览说明（v2 全栈版）
=============================================

最简单的方式（无需数据库）：

1. 安装 Node.js 20 或更高版本（https://nodejs.org）
2. 解压本压缩包，进入 app 目录
3. 执行：
     npm install
     npm run dev
4. 浏览器打开 http://localhost:3000

说明：
- 开发模式下无需数据库即可体验全部界面与功能
- 无数据库时应用自动以「离线模式」运行：数据保存在浏览器本地，功能不受影响
- 手机预览：电脑和手机连同一 WiFi，执行 npm run dev -- --host，
  用手机访问 http://电脑IP:3000

如果已有 MySQL 数据库，在 app 目录新建 .env 文件写入：
  DATABASE_URL=mysql://用户名:密码@127.0.0.1:3306/koreanflow
  APP_ID=local
  APP_SECRET=任意随机字符串
重启后学习数据将同步到数据库（表结构自动创建）。
