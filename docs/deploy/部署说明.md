# KoreanFlow「韩之语」自有服务器部署指南（v2 全栈版）

> **v2 重要变化**：应用已从纯静态站点升级为**全栈应用**（React 前端 + Hono/tRPC 后端 + MySQL 数据库）。
> 数据库存储用户档案、学习统计、偏好设置、复习记录、生词本云端同步与语料元数据，为后续登录和付费功能做准备。
> 服务器需要 **Node.js 20+** 和 **MySQL 8+**（或兼容的 TiDB）。

---

## 1. 你需要准备什么

| 项目 | 说明 |
|---|---|
| 服务器 | Linux 云服务器（建议 1核2G 起），已安装 Node.js 20+ 与 Nginx |
| 数据库 | MySQL 8+（本机安装或云 RDS 均可），建一个空库如 `koreanflow` |
| 域名（强烈推荐） | 已解析到服务器 IP，用于 HTTPS（录音/PWA 必需） |
| 部署文件 | 本目录下的 `dist/`（构建成品，含前端 `dist/public/` + 服务器 `dist/boot.js`） |

## 2. 部署步骤

### 2.1 上传成品

```bash
# 本地执行：把整个 dist 目录上传
scp -r dist root@你的服务器IP:/var/www/koreanflow/
```

### 2.2 配置数据库连接

在服务器上创建环境文件 `/var/www/koreanflow/.env`：

```bash
DATABASE_URL=mysql://用户名:密码@127.0.0.1:3306/koreanflow
APP_ID=self-hosted
APP_SECRET=任意随机字符串
```

> 数据库表**无需手工创建**——服务器首次启动时会自动建表并灌入内置词库/句库（幂等，重复启动无副作用）。

### 2.3 启动应用

```bash
cd /var/www/koreanflow
# dist/boot.js 是零依赖打包产物（esbuild bundle），无需 node_modules
NODE_ENV=production PORT=3000 node dist/boot.js
```

生产建议用 pm2 守护：

```bash
npm i -g pm2
cd /var/www/koreanflow
NODE_ENV=production pm2 start dist/boot.js --name koreanflow --env production
pm2 save && pm2 startup        # 开机自启
```

验证：`curl http://127.0.0.1:3000/api/trpc/ping` 返回 JSON 即后端正常。

### 2.4 Nginx 反向代理

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

```bash
sudo nginx -t && sudo systemctl reload nginx
```

> 服务器自带 SPA 回退（直接访问 `/corpus` 等子路由不会 404），Nginx 只做反代即可。

### 2.5 HTTPS（必须）

🎤 录音跟读与 📱 iOS 主屏幕安装都要求安全上下文：

```bash
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
```

## 3. iPhone / PC 访问

- PC：浏览器访问 `https://your-domain.com`
- iPhone：Safari 打开 → 分享 →「添加到主屏幕」
- 无发音时：iOS 设置 → 辅助功能 → 朗读内容 → 声音，下载韩语语音

## 4. 日常更新

```bash
# 本地有 Node 20+ 的机器上，源码目录内：
npm install
npm run build                      # 产出 dist/（前端 + boot.js）
rsync -avz --delete dist/ root@你的服务器IP:/var/www/koreanflow/dist/
ssh root@你的服务器IP "pm2 restart koreanflow"
```

> 数据库表结构变更无需手动迁移——启动时自动同步（CREATE TABLE IF NOT EXISTS）。

## 5. 架构与数据说明

- **数据库表**（9 张）：`users`（预留 openid/会员字段）、`preferences`、`stats`、`study_sessions`、`review_records`、`system_words`（84 内置词）、`system_sentences`（每日一句+发音句）、`user_vocab`（生词本云同步）、`user_corpus`（语料元数据）
- **身份机制**：当前为匿名设备用户（浏览器生成 deviceId 自动建档）；users 表已预留 `openid` 与 `plan`（free/pro）字段，未来接入登录/付费时平滑升级
- **媒体文件**：用户上传的音视频/PDF 本体仍存在其浏览器 IndexedDB（节省服务器存储与带宽），数据库只存元数据；跨设备不共享媒体本体
- **离线降级**：后端/数据库不可达时，前端自动切换 localStorage 离线模式，功能不受影响，恢复后自动同步

## 6. 注意事项

- 备份：定期 `mysqldump koreanflow > backup.sql`
- 轻量替代：如果暂不需要数据库，也可以只部署 `dist/public/` 为纯静态站（沿用 v1 静态方案），前端会自动离线运行，但用户中心云端同步不可用
- 源码在 `app/` 目录（含 `api/` 后端、`db/` 数据库定义），结构清晰带中文注释，可自由二次开发
