# 语料中心页 (Corpus / 用户语料库)

**目标**: 用户上传音频、视频、PDF、文本语料，进行阅读 / 听力（波形 + A-B 循环）/ 发音练习，支持选词翻译弹气泡。数据存 IndexedDB，离线可用。

---

## Section 1 — 页头 + 上传区

**布局**: 左标题（主标 30px「语料中心」+ 副标「나만의 코퍼스 · 我的语料库」+ 说明「上传韩剧片段、播客、课文 PDF……把喜欢的材料变成练习场。文件只保存在你的浏览器里。」）；右侧 StatChip「已存语料 N 份 · 共 XX MB」。

**上传卡片**: 大面积虚线边框拖放区（2px dashed `border-warm`，hover/拖拽悬停时边框变赤陶橘 + 底色转 `accent-terracotta-soft`），中央图标（☁️↑ 48px 浅褐）+「拖文件到这里，或 点击选择」+ 支持格式说明 12px 浅褐：「音频 mp3/wav/m4a · 视频 mp4/webm · 文档 pdf/txt/md · 单文件 ≤ 200MB」。
- 上传后显示处理条（文件名 + 进度条动画），完成弹 Toast「已加入语料库」。

**Animation**: 页头标题词级上入；拖放区常态下虚线框做 8s 缓慢呼吸（opacity 0.7→1）；拖入时整个区域 scale 1.01 + 边框实线化（200ms）。

## Section 2 — 语料库列表

**布局**: 网格卡片（桌面 3 列 / 移动 1 列）。每张语料卡：
- 顶部类型徽章（🎧音频 赤陶橘 / 🎬视频 蜂蜜金 / 📄PDF 橄榄绿 / 📝文本 暖灰褐）+ 文件名（截断 1 行）+ 元信息（时长/页数/字数 · 大小 · 添加日期）。
- 音频卡内嵌迷你波形（预生成 peaks 渲染成 40px 高 SVG，赤陶橘）。
- 底部:「打开练习 →」主链接 + 右键/⋯ 菜单（重命名 / 删除，删除需二次确认 Modal「将从本机删除该文件」）。
- 空状态：`/empty-corpus.svg` +「语料库还是空的。上传第一段材料，开始精听精练。」+「立即上传」按钮（滚动聚焦到拖放区并高亮脉冲两次）。

**Animation**: 卡片 stagger 0.08s 上移 24px 淡入；hover translateY -4px + `shadow-lift`；删除时卡片 scale 0.95 淡出 + 网格重排（Framer Motion layout 动画）。

## Section 3 — 练习工作台（打开语料后，整页视图）

顶部返回栏：「← 返回语料库」+ 语料名 + 类型徽章。

### 3a. 音频模式（核心）

- **波形可视化区**: 全宽纸白面板内嵌 WaveSurfer 波形，高度 96px；未播放部分暖灰褐 `#A79C90`，已播放部分赤陶橘，游标竖线 2px 墨褐。点击波形任意处跳转。
- **A-B 循环**: 波形上拖拽划定选区（选区填充 `accent-terracotta-soft` 50% + 两端赤陶橘手柄）；下方控制条显示 `A 00:12.4 — B 00:18.9`，按钮组：「设置 A」「设置 B」「清除循环」「循环次数 ∞/3/5」下拉。循环播放到 B 点自动跳回 A（timeupdate 轮询）。
- **播放控制行**: ⏮ -5s / ▶⏸ 大圆钮（赤陶橘 56px）/ +5s ⏭ / 速度 0.5×–1.5× 步进 0.25（pill 显示当前倍速）/ 音量滑条（自定义 4px 暖褐轨道）。
- **跟读区**（可选展开面板）:「跟着这段读」——录音钮 + 回放 + 与 A-B 段对比播放（复用发音练习页组件）。

### 3b. 视频模式

- 16:9 播放器（24px 圆角纸白面板内），原生 controls 隐藏，自定义同 3a 的控制行 + A-B 循环；视频下方迷你波形（音频轨）辅助定位。

### 3c. PDF / 文本阅读模式（选词翻译核心场景）

- 阅读区最大宽 760px 居中，纸白「书页」卡片（24px 圆角 + `shadow-card` + 内边距 48px），韩语正文 Noto Serif KR 18px / 2.0 行高；PDF 用 pdf.js 提取文本层渲染为可选取文本（保留分页导航「‹ 3 / 12 ›」）。
- **选词翻译气泡**: 鼠标划词 / iOS 长按选中单词 → 在选区上方弹出气泡（纸白 12px 圆角 + 小三角指向）：
  - 韩语词 20px 衬线 + 罗马音 + 中文释义（查本地词典 `dictionary.ts`）+ 小喇叭发音 + 「☆ 加入生词本」（写入 `vocab-favorites`）。
  - 词典未命中：显示「本地词典未收录」+「试试整句 TTS 朗读」按钮。
  - 气泡定位:选区 getBoundingClientRect，防溢出左右钳制 8px；点击空白处或 Esc 关闭。
- 阅读工具条（粘性底部，移动端置于安全区上方）：字号 A- / A+ / 行距切换 / 「全文朗读」TTS 按钮。

**Animation**: 工作台进入时波形面板从下方上入 32px（400ms）；A/B 手柄设置瞬间在波形上弹跳 1.15→1（spring）；翻译气泡 scale 0.85→1 + 上移 6px 淡入（180ms）；全文朗读时当前句高亮暖沙底逐句推进。

## Section 4 — 存储管理

- 页底暖沙小条：📦「本地存储已用 XX MB（IndexedDB）」+「导出我的数据（JSON）」「清空全部语料」（二次确认）。导出包含生词本、进度、语料元信息（文件本体提示重新上传）。

## 技术约定

- 文件 Blob 存 IndexedDB（store `corpus-files`），元信息存 `corpus-meta`；localStorage 仅存 UI 偏好。
- 波形 peaks 在上传时计算并存入 IndexedDB，打开时秒渲染；大文件（>50MB）降级为实时解码。
- iOS 注意：`playsinline` 视频、音频解锁需用户手势后首次 play、IndexedDB 在 PWA 模式可用。
- 本地词典 `src/data/dictionary.ts`：≥800 高频词条 `{ ko, rom, zh, pos }`。

**移动端**: 工作台控制行两行排布；波形高度降至 64px 且支持触摸拖拽选区（手柄放大至 28px 热区）；阅读页工具条固定底部。
