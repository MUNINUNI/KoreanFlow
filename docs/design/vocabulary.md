# 单词学习页 (Vocabulary / 词卡 + 生词本)

**目标**: 翻卡式背单词 + 可收藏的个人生词本，全部 localStorage 本地存储。

---

## Section 1 — 页头 + 模式切换

**布局**: 左标题右统计。主标 30px「单词学习」，副标韩语小字「단어 공부」。
- 顶部 pill 切换组（分段控制器）:**学习模式 | 生词本 | 全部词库**，激活段赤陶橘实底白字，滑块用 layoutId 动画过渡。
- 右侧 StatChip：「今日已学 8/20」「生词 15」。

**Animation**: 切换段时内容区交叉淡入（200ms），列表项重新 stagger。

## Section 2 — 学习模式（词卡翻转）

**布局**: 居中主舞台。大卡 480×320px（移动端全宽 × 300px），透视 1200px：
- **正面**: 分类小标签（蜂蜜金，如「日常问候」）+ 韩语词 Serif KR 40px（**안녕하세요**）+ 罗马音 + 中央 SpeakButton（lg）。
- **背面**: 中文释义 24px（你好）+ 词性标签（感叹词）+ 例句一句（韩语 + 中文，各带小喇叭）+ 收藏星。
- 卡片下方控制条：「← 上一个」「翻面（或点击卡片）」「认识 ✓」「模糊 ~」「下一个 →」。「认识」橄榄绿描边、「模糊」陶红描边——点击后自动切下一词并计入进度。
- 顶部细进度条：本组 20 词已完成度（赤陶橘填充，宽度动画 300ms）。
- 分类选择：页头下方横向滚动胶囊（问候 / 数字时间 / 食物 / 出行 / 购物 / 情感 / 校园），选中实心。

**Animation**: 翻面 rotateY 0→180°（600ms, easeOutQuint），背面从 rotateY -180° 归位；切词时卡片横向滑出 40px 淡出、新卡滑入（280ms）；「认识」点击时卡片右上角弹出橄榄绿 +1 飘分动画。

## Section 3 — 生词本

**布局**: 列表式（非卡片网格），每行一条纸白横条：韩语词（20px 衬线）| 中文释义 | 添加日期 | 发音钮 | 已掌握 toggle | 删除（垃圾桶图标，hover 变陶红）。
- 顶部工具行：搜索框（🔍 占位「搜索韩语或中文…」，输入 300ms 防抖实时过滤）+ 「按日期/按掌握度排序」下拉 + 「全部标记已掌握」「清空生词本」（二次确认 Modal）。
- 空状态：`/empty-vocab.svg` + 「还没有生词。学习词卡时点 ☆ 收藏，或在每日一句里点收藏。」+「去学习 →」按钮。
- 已掌握词整行降透明度至 55%，韩文左侧橄榄绿圆点。

**Animation**: 列表进入视口 stagger 0.05s 上移 16px 淡入；删除时行高度折叠 + 左滑淡出（250ms）；toggle 切换时绿点 scale 弹入。

## Section 4 — 全部词库

**布局**: 按分类分组的卡片网格（桌面 4 列 / 移动 2 列），每张小词卡：韩语词 + 罗马音 + 中文（默认只显示韩语，「显示释义」总开关控制）；点击播放发音，长按/右键弹出「加入生词本」。
- 组标题：分类名 + 组内掌握度迷你进度条。

**Animation**: 分组依次入场 stagger；释义开关切换时中文行高度展开动画（200ms）。

## Section 5 — 底部学习建议

- 暖沙提示条：💡「艾宾浩斯建议：收藏的生词在第 1、3、7 天复习效果最好。」（静态，入场淡入上移 20px）。

## 数据与存储约定

- 内置词库 `src/data/words.ts`：≥200 词，字段 `{ id, ko, rom, zh, pos, exampleKo, exampleZh, category }`。
- localStorage key：`vocab-progress`（认识/模糊标记）、`vocab-favorites`（生词本数组，含添加时间戳与掌握标记）、`vocab-daily`（今日已学计数，按日期重置）。
- 首页「每日一句」收藏按钮写入同一 `vocab-favorites`。

**移动端**: 词卡舞台顶部固定；翻面手势支持左右滑动切词（Framer Motion drag x，阈值 80px）；生词本行内操作改为滑动露出删除按钮。
