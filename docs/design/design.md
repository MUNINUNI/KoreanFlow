# 韩语学习工具 PWA — 全局设计文档

## 产品概述

**产品名**:「韩之语 HanJiYu」— 一款离线优先的韩语学习工具 PWA
**形态**: 响应式 Web App (PWA)，PC 桌面端 + iOS Safari 直接使用，可添加到主屏幕
**语言**: 全中文界面（学习内容为韩语）
**核心理念**: 「温暖纸感 × 留白呼吸 × 触手可及的发音」——像一本精心排版的韩语手账，低饱和暖色营造沉浸、无压力的学习氛围。

---

## 设计风格方向

- **低饱和暖色系**: 米白纸底、暖杏、赤陶橘、橄榄绿点缀；**严禁蓝紫渐变**、严禁高饱和霓虹。
- **纸感纹理**: 极轻噪点/纸张纹理背景，卡片微暖阴影，像翻阅精装手账。
- **充足留白**: 内容区最大宽度 1120px，段落间距慷慨，模块间 96–160px 呼吸空间。
- **清晰层级**: 中文标题（衬线宋体气质）+ 韩语正文（现代无衬线），大小对比 ≥2:1。
- **微动效克制**: 卡片悬停轻抬升、按钮按压回弹、音节点击时的「声波涟漪」——动效服务于反馈，不炫技。

**字号阶梯** (桌面): 12 / 14 / 16(base) / 18 / 20 / 24 / 30 / 38 / 48 / 60
- Hero 主标 48–60px 衬线；模块标题 30px；卡片标题 20px；正文 16px/1.8 行高。
- 韩语展示字（40音、词卡）放大 1.25 倍：词卡韩文 32–40px。

## 间距与圆角

- 间距刻度: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128px。
- 圆角: 小件 8px，卡片 16px，大面板/模态 24px，按钮 pill（999px）或 12px。
- 卡片描边 1px `border-warm` + 轻阴影，不用重边框。

## 动画风格

- **曲线**: 全局 `cubic-bezier(0.22, 1, 0.36, 1)`（easeOutQuint 质感）；交互反馈 150–250ms，入场 400–700ms。
- **入场**: 元素上移 24–40px + 透明度 0→1，同组 stagger 0.06–0.1s，IntersectionObserver 在元素进入视口 20% 处触发。
- **页面切换**: Framer Motion `AnimatePresence`，旧页淡出下移 12px（200ms），新页上入 16px（300ms）。
- **发音反馈**: 点击字母/喇叭时，从中心扩散 2 圈涟漪（scale 0.8→1.6，opacity 0.5→0，600ms），图标做 1→0.9→1 缩放脉冲。
- **滚动**: Lenis 平滑滚动（PC），iOS 用原生滚动；锚点平滑定位。
- **克制**: 同一视口内动效元素 ≤8 个，无持续循环背景动画（学习工具需专注）。

## 导航与布局结构

### PC (≥1024px)
- 顶部固定导航栏：高 64px，纸白底 + 底部 1px 暖线，滚动时加轻阴影。
- 左侧：Logo（印章式方块 + 「韩之语」衬线字）；中间：导航链接（首页 / 40音入门 / 单词学习 / 发音练习 / 语料中心）；右侧：深色模式切换 + 学习统计入口（火焰连续天数图标）。
- 当前页链接：赤陶橘字色 + 下方 2px 圆角下划线（layoutId 动画滑动）。

### iOS / 移动 (<1024px)
- 顶部精简栏（Logo + 统计）；**底部 Tab Bar**（5 个图标标签，安全区适配 `env(safe-area-inset-bottom)`），激活态赤陶橘 + 图标上跳微动效。
- iOS PWA meta：`apple-mobile-web-app-capable`、`viewport-fit=cover`、触摸高亮关闭、`-webkit-tap-highlight-color: transparent`。

### 页脚 (PC)
- 暖沙底，三栏：品牌标语「每天一句，慢慢开口说韩语」/ 功能导航 / 离线说明（「所有数据仅存储于本机浏览器」）+ PWA 安装提示按钮。移动端页脚精简为单行版权。

## 共享组件清单

1. **AppShell** — 导航 + 页面容器 + Tab Bar + 页脚。
2. **SectionHeading** — 衬线中文大标 + 韩语小字副标（如 `매일 조금씩`）+ 装饰性短线。
3. **SpeakButton** — 通用 TTS 发音按钮（喇叭图标 + 涟漪动效），props: `text`, `rate`(0.6–1.2), 尺寸 sm/md/lg。
4. **WordCard** — 词卡（韩语词 + 罗马音 + 中文释义 + 例句 + 收藏星 + 发音钮），支持 3D 翻面（rotateY 180°, 600ms）。
5. **Toast** — 底部胶囊提示（「已加入生词本」），Framer Motion 弹入，2.5s 自动消失。
6. **StatChip** — 统计徽章（连续天数 / 已学单词 / 今日进度）。
7. **EmptyState** — 空状态插画（SVG）+ 引导文案 + CTA 按钮。
8. **Modal / Drawer** — 纸白底、24px 圆角、背景暖色半透明遮罩（`rgba(46,42,38,0.4)`），移动端抽屉从底部上滑。
9. **ProgressRing** — SVG 圆环进度（今日目标、40音掌握度）。

## 技术架构约定（供实现参考）

- **TTS**: Web Speech API `speechSynthesis`，`lang='ko-KR'`，自动挑选韩语 voice；不支持时降级提示。
- **本地存储**: localStorage 存设置/生词本/收藏/进度（JSON）；IndexedDB (idb) 存用户上传的语料文件 Blob（音频/视频/PDF/文本）。
- **离线**: Service Worker 预缓存应用壳 + 字体 + 静态语料；`manifest.json` 定义图标、主题色 `#FAF6F0`、standalone 显示。
- **波形**: WaveSurfer.js（ peaks 预计算可选）；A-B 循环用 `setLoop` / timeupdate 判定。
- **选词翻译**: 鼠标/触摸选中文本 → `window.getSelection()` 定位 → 弹翻译气泡（内置词典 JSON 查词 + 可选网络释义，离线时用本地词典）。
- **代码结构**: `src/pages/`（每页一文件）, `src/components/`（共享组件）, `src/lib/`（tts.ts, storage.ts, dictionary.ts, corpus.ts）, `src/data/`（hangul.ts, words.ts, sentences.ts），关键函数中文注释。
