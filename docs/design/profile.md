# 用户中心页 (Profile / 我的)

**路由**: `/profile`
**目标**: 用户身份卡 + 学习数据总览（大数字 + 近7天柱状图）+ 学习偏好设置（即时保存）+ 数据管理。全部数据本地优先，后端同步复用既有接口。

---

## 数据与存储约定

| 数据 | localStorage Key | 说明 |
|---|---|---|
| 偏好设置 | `hjy:review-prefs` | `{ groupSize: 10, voice: 'female', dailyGoal: 5 }`，与复习页共用同一 key（复习节奏 groupSize 3–50 默认 10；每日目标 1–50 默认 5） |
| 学习统计 | `hjy:stats` | `{ totalWords, totalSentences, totalMinutes, streak, daily: { 'YYYY-MM-DD': minutes } }`；由各学习页埋点累加，本页只读 |
| 语音音色 | 同上 `voice` 字段 | `'female' 清亮女声 / 'male' 清亮男声`，全局 TTS（`tts.ts`）读取该值挑选 voice |
| 导出数据 | — | 聚合所有 `hjy:*` key + `vocab-*`、`pron-*` 历史 key 生成 JSON 下载 |
| 清除数据 | — | 二次确认后 `localStorage.clear()`（仅本应用 key）+ 清空 IndexedDB 语料，刷新回首页 |

**布局（桌面）**: 内容区 1120px 居中。主标 30px 衬线「我的」+ 韩语副标「마이 페이지」。下方用户卡：纸白 24px 圆角 + `shadow-card`，横向布局（移动端纵向居中）：

## Section 2 — 学习数据区

### 2.1 大数字统计卡（4 张）

**布局**: 桌面 4 列网格 / 移动端 2×2 网格，间距 16px。每张纸白卡 16px 圆角 + `shadow-card`，居中大数字 + 标签：
1. **累计单词** `128` 词 —— 图标 📖 蜂蜜金
2. **累计句子** `56` 句 —— 图标 💬 赤陶橘
3. **累计时长** `12 小时 30 分`（≥1 小时显示「X 小时 Y 分」，不足显示「Y 分钟」）—— 图标 ⏱ 橄榄绿
4. **连续学习** `5` 天 —— 图标 🔥 赤陶橘；下方加一行 12px 浅褐「最长连续 14 天」

- 数字 38px Noto Serif SC 600 墨褐，标签 14px 暖灰褐。
- 数据从 `hjy:stats` 读取；全部为 0 时不显示空状态，显示「0」+ 标签下灰字「今天就开始第一课吧」。

**Animation**: 卡片 stagger 0.08s 上移 24px 淡入；数字做 count-up 滚动（从 0 到目标值，800ms, easeOutQuint，仅在进入视口时触发一次）。

### 2.2 近 7 天学习时长柱状图（纯 CSS/div 实现）

**布局**: 纸白大面板 24px 圆角，内边距 32px：
- 标题行：「近 7 天学习时长」18px 衬线 + 右侧小字「共 95 分钟」。
- 图表区：7 根等宽竖条（div，宽 32px，圆角顶部 6px），高度 = 当日分钟数 / 7 天最大值 × 160px（最小高度 4px 保证可见）；条色 `accent-terracotta`，**今天**的条用 `accent-olive` 区分。
- 每根条下方：星期标签 12px 浅褐（一/二/…/今天）；hover（或触摸）时条上浮 tooltip：纸白小气泡「8月11日 · 25 分钟」。
- 无数据日：条以最小高度 4px + `bg-sand` 显示。
- 全 7 天无数据：图表区显示浅褐居中文案「最近还没有学习记录」+「去学习 →」文字链。

**Animation**: 面板进入视口时 7 根条从底部 scaleY 0→1 生长（transform-origin: bottom，stagger 0.06s，500ms, easeOutQuint）；tooltip scale 0.9→1 淡入（150ms）。

## Section 3 — 学习偏好设置

**布局**: 纸白大面板 24px 圆角，标题「学习偏好」20px 衬线 + 副标「修改即时保存，并自动同步」。三个设置项纵向排列，项间 1px `border-warm` 分隔线，每项左标签右控件（移动端纵向堆叠）：

### 3.1 复习节奏（每组单词数）
- 标签：「复习节奏」+ 说明 13px 浅褐「每次复习一组的词条数量」。
- 控件：**步进器 + 滑块组合**——左侧自定义滑块（轨道 4px `bg-sand`、已选段赤陶橘、圆形手柄 20px 纸白 + `shadow-card`，拖拽时手柄 scale 1.15），右侧步进器（圆角 12px 框，「−」「＋」按钮 + 中央数字 18px，范围 3–50，默认 10，长按连续步进）。
- 当前值下方小字预览：「每组 10 词 · 大约 3 分钟一组」。

### 3.2 语音音色（单选卡片）
- 标签：「语音音色」+ 说明「全局韩语朗读的声音」。
- 控件：两张横向单选卡（移动端纵排），每张纸白 16px 圆角 + 1px 描边：
  - **「🎀 清亮女声」** —— 副标「柔和清晰，适合跟读」
  - **「🎩 清亮男声」** —— 副标「低沉稳重，适合精听」
  - 选中态：描边变赤陶橘 2px + 底色 `accent-terracotta-soft` + 左上角橄榄绿对勾圆点 scale 弹入；未选中 `border-warm`。
  - 每张卡右侧**「▶ 试听」**小按钮（描边 pill）：用对应音色 TTS 说固定示例句「안녕하세요, 만나서 반갑습니다.」（你好，很高兴见到你）；播放中按钮变为声波柱跳动动画（0.8s 循环，同发音练习页）。

### 3.3 每日目标
- 标签：「每日目标」+ 说明「每天想学习的句子数量，首页会显示进度」。
- 控件：步进器（同 3.1 样式，范围 1–50，默认 5）+ 右侧预览胶囊「每天 5 句 · 一年 1825 句」。

**保存反馈**: 任一修改立即写 `hjy:review-prefs`，控件旁浮现橄榄绿小对勾「已保存」（淡入 200ms，1.5s 后淡出），并静默调用后端同步（失败不打扰用户，标记待重试）。

**Animation**: 面板入场 stagger 0.1s 上移 24px；单选卡切换时描边色过渡 200ms + 对勾 scale 0→1 spring；滑块数值变化时预览文字交叉淡入。

## Section 4 — 数据管理

**布局**: 纸白面板 24px 圆角，标题「数据管理」20px 衬线 + 说明「所有数据默认只保存在本机浏览器」。两个操作行（移动端纵排）：
1. **📦 导出我的数据**: 赤陶橘描边按钮「导出 JSON」——点击聚合全部学习数据（生词本 / 复习记录 / 统计 / 偏好 / 语料元信息）生成 `koreanflow-backup-YYYYMMDD.json` 下载；完成 Toast「数据已导出」。
2. **🗑 清除本地数据**: 陶红描边按钮「清除全部数据」——点击弹出二次确认 Modal：
   - 标题「确定要清除所有本地数据吗？」+ 正文「将删除生词本、学习记录、统计与语料文件，此操作不可恢复。建议先导出备份。」
   - 按钮：「取消」（描边）/「确认清除」（陶红实底）；确认后清空本应用 localStorage key + IndexedDB，Toast「已清除」并 1s 后跳转首页。

**Animation**: 按钮 hover translateY -2px + `shadow-lift`；危险按钮 hover 底色转浅红；Modal 从下方上滑 24px + 遮罩淡入（250ms）。

## Section 5 — 状态设计

| 状态 | 表现 |
|---|---|
| **全新用户（无统计）** | 数字卡显示 0，柱状图区显示引导文案（见 2.2）；用户卡时长摘要隐藏。 |
| **同步失败/离线** | 偏好保存的对勾文案变为「已保存在本机」（蜂蜜金），不打断操作。 |
| **TTS 不可用** | 试听按钮置灰 + 一次性 Toast「当前浏览器不支持韩语语音朗读」。 |
| **导出失败（极少数）** | Toast「导出失败，请重试」（陶红图标）。 |

## 移动端适配

- 用户卡纵向居中（头像 → 昵称+徽章 → 摘要）；统计卡 2×2 网格；柱状图条宽缩至 24px、热区扩至 44px，hover tooltip 改为点按切换。
- 设置项全部纵向堆叠，滑块全宽；音色单选卡纵排。
- 各区块与底部 Tab Bar 之间预留 `env(safe-area-inset-bottom)`。

## 令牌对应速查

卡片 `bg-paper`+`shadow-card`+16/24px 圆角；分区与禁用底 `bg-sand`；主强调 `accent-terracotta`（滑块、步进器、选中描边），成功/保存反馈 `accent-olive`，会员徽章与试听 `accent-honey`，危险操作 `accent-clay-red`；文字 `ink-primary/secondary/muted`；描边 `border-warm`；动画曲线 `cubic-bezier(0.22,1,0.36,1)`，入场 stagger 0.08–0.1s。
