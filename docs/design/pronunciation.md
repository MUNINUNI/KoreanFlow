# 发音练习页 (Pronunciation / 跟读练习)

**目标**: 分级句子跟读——听 TTS 范读（常速/慢速）、录下自己的跟读并回放对比，逐句打磨。

---

## Section 1 — 页头

- 主标 30px「发音练习」，副标韩语小字「발음 연습」，说明 16px 暖灰褐：「先听范读，再按下录音跟读，回放对比找差距。录音只存在本机，用完即焚。」
- 右侧 StatChip:「今日已练 5 句」。

**Animation**: 标题词级上移 24px 淡入 stagger 0.08s。

## Section 2 — 难度分级 Tab

- 三段 pill 切换：**初级（日常短句）/ 中级（生活对话）/ 高级（新闻·台词节选）**，激活赤陶橘。每级内句子列表纵向排布（本页直接列出全部，10 句/级，虚拟滚动非必需）。

**Animation**: 切换时滑块 layoutId 过渡 + 列表 stagger 0.05s 上入 16px。

## Section 3 — 练习卡片（核心单元，每句一张）

**布局**: 纸白卡片 20px 圆角，内部分上下两区：
- **句子区**: 左侧序号圆点（蜂蜜金描边）+ 韩语句子 Serif KR 24px + 罗马音 13px 浅褐 + 中文释义 16px。
- **控制区**（底部一行，移动端换行为两行）:
  1. 🔊 **常速范读** SpeakButton（md）
  2. 🐢 **慢速 0.6×** 按钮（描边 pill）
  3. ⏺ **跟读录音**（大圆钮 56px，赤陶橘；录音中变陶红脉冲 + 外圈波纹扩散动画 1.2s 循环）
  4. ▶ **回放我的录音**（有录音后启用，灰色禁用→可用）
  5. 🔁 **对比播放**（先放范读、间隔 0.5s 再放用户录音，按钮文字「范读→我」）
  6. ✓ **标记已练**（橄榄绿描边 toggle，已练卡片左上角显示橄榄绿「已练」缎带角标）
- 录音请求 `getUserMedia`；拒绝授权时 Toast「需要麦克风权限才能跟读哦」，录音钮降级禁用，其余功能不受影响。

**Animation**: 卡片进入视口 stagger 0.07s 上移 24px；播放中的按钮显示等距 3 条声波柱跳动动画（CSS keyframes 0.8s）；「标记已练」点击时缎带从右上方 rotate 45° 滑入（spring）。

## Section 4 — 连读/发音规则小贴士

**布局**: 「韩国人不会告诉你的 4 条发音规则」横向滚动卡片列（桌面 4 张同排，移动端横向 snap 滚动）:
1. **连音化** 사랑해요 → [사랑해요] 实际读法说明
2. **紧音化**  학교 → [학꾜]
3. **同化**  입니다 → [임니다]
4. **ㅎ 弱化** 좋아요 → [조아요]
- 每张卡：规则名 18px + 例子（韩语 → [实际发音]，发音部分赤陶橘）+ 小喇叭播放例子。

**Animation**: 卡片 stagger 0.1s 上入；横向滚动条自定义 4px 暖褐圆角。

## Section 5 — 底部引导

- 暖沙条：「想用真实韩剧台词、播客练发音？去语料中心上传你的材料 →」按钮。

## 数据与技术约定

- 句子库 `src/data/sentences.ts`：3 级 × 10 句，字段 `{ id, level, ko, rom, zh, tip? }`。
- 录音用 MediaRecorder（iOS Safari 支持 audio/mp4），Blob 仅存内存（URL.createObjectURL 回放），刷新即清，不落盘。
- 已练标记 localStorage `pron-done: string[]`；今日计数 `pron-daily`。

**移动端**: 录音大圆钮固定于控制区中央突出显示；卡片内字号降档（韩语 20px）；横向规则卡 snap-align: start。
