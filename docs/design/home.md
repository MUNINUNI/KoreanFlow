# 首页 (Home / index)

**目标**: 3 秒内让用户听到今天的韩语句子，并一眼看到全部功能入口与自己的学习进度。

---

## Section 1 — Hero 主视觉

**布局**: 桌面两栏（左文 55% / 右图 45%），垂直居中，整屏高约 88vh；移动端单栏，图在文下。
- 左：蜂蜜金小标签「오늘도 화이팅 · 今天也加油」（12px 大写字距 2px 中文）；主标题衬线 48–60px:「每天一句，慢慢开口说韩语。」（「开口说韩语」用赤陶橘）；副文案 16px 暖灰褐：「从 40 音到真实语料，听说读写一站式韩语自习室。所有数据保存在本机，离线也能学。」
- CTA 组：主按钮「开始今日学习 →」（赤陶橘实心 pill，hover 加深为 `#B4552D` + 右移 2px 箭头）；次按钮「学习 40 音」（纸白描边 pill）。
- 按钮下方一行轻提示：🔊 图标 +「支持离线使用 · 可安装到主屏幕」（12px 浅褐）。
- 右：`/hero-illustration.png` 插画，置于 24px 圆角暖沙底卡片内，卡片下方垫一张旋转 -3° 的描边卡片制造手账层叠感。

**Animation**: 页面加载时——标签 fade-in（0ms），主标题按词上移 30px 淡入 stagger 0.08s（100ms 起），副文案与 CTA 在 400ms 时上入；插画卡片从 scale 0.94 + rotate 2° 归位（700ms, easeOutQuint）。插画内韩文字符做 ±6px 的 6s 慢速浮动循环（仅 3 个字符，符合动效克制原则）。主按钮 hover: scale 1.03；按下 scale 0.97。

## Section 2 — 每日一句（核心卡片）

**布局**: 居中大卡片，最大宽 880px，纸白底 + `daily-texture.svg` 点纹背景 + 24px 圆角 + `shadow-card`。卡片内结构：
- 顶部一行：蜂蜜金「每日一句 Daily Sentence」标签 + 日期（2025年×月×日 星期×）；右侧「换一句」图标按钮（循环箭头）。
- 韩语句子衬线大字 32–40px 居中（例：**천천히 가도 괜찮아, 멈추지만 않는다면.**），悬停任一词高亮暖沙底。
- 罗马音一行 14px 浅褐斜体；中文释义 18px 墨褐：「慢慢走也没关系，只要不停下来。」
- 底部操作条：大号 `SpeakButton`（常速）+ 慢速 0.7× 按钮 + 「收藏」星标（点击填充蜂蜜金并弹 Toast「已收藏到生词本」）+ 单词拆解折叠区（列出句中单词 → 词性/释义，每个词旁小喇叭可单独发音）。

**Animation**: 卡片滚动至视口 25% 时上移 32px 淡入（500ms）。点击发音时喇叭涟漪 + 句子整体亮度微脉冲。换句：旧句左滑淡出 200ms，新句右滑淡入 300ms。

## Section 3 — 今日学习概览

**布局**: 一行四张 `StatChip` 卡片（移动端 2×2 网格），纸白卡片 16px 圆角：
- 🔥 连续学习 **7 天**（火焰蜂蜜金）｜ 📖 已学单词 **128** ｜ 🎯 今日目标 **3/5 句**（嵌 ProgressRing）｜ 🔤 40音掌握 **60%**
- 数据全部读 localStorage；为 0 时显示友好占位（「从今日第一句开始」）。

**Animation**: 进入视口时四卡 stagger 0.1s 上入 24px；数字做 0→目标值的 800ms 计数动画（ease-out）。

## Section 4 — 功能入口（四大模块卡）

**布局**: 2×2 网格（移动端纵向堆叠），卡片高 220px，悬停时 translateY -6px + `shadow-lift`（250ms）：
1. **40音入门** — 橄榄绿标签；大字「가」字符装饰；「21 个元音 · 19 个辅音，点击即发音」
2. **单词学习** — 赤陶橘标签；词卡叠放图标；「分类词卡 + 个人生词本」
3. **发音练习** — 蜂蜜金标签；声波纹图标；「常速/慢速跟读，逐句打磨」
4. **语料中心** — 陶红标签；文件夹+波形图标；「上传你的音频/视频/PDF，A-B 循环精听」
- 每卡右下角「进入 →」链接，hover 时箭头位移。

**Animation**: 进入视口 stagger 0.12s 上移 32px 淡入；卡内装饰字符 hover 时轻微 rotate ±4°。

## Section 5 — 学习路径（如何开始）

**布局**: 横向 4 步时间线（桌面），移动端纵向；节点为赤陶橘圆点 + 连线（虚线 `border-warm`）：
1. 认识 40 音 → 2. 积累核心词汇 → 3. 跟读练发音 → 4. 用真实语料沉浸
- 每步配一句话说明 + 对应页面链接。

**Animation**: 滚动驱动——连线从左至右描边生长（scroll progress 0→100% 映射 path dashoffset），节点依次 scale 0.6→1 弹入。
