# 复习页 (Review / 三模式复习中心)

**路由**: `/review`
**目标**: 一个页面聚合三种复习模式——闪卡复习 / 拼写练习 / 发音复习，内容来自用户生词本 + 系统词库 + 每日一句/发音句库；按组推进、组末小结庆祝，结果落盘 localStorage 并尝试同步后端。

---

## 数据来源约定

| 数据 | localStorage Key | 说明 |
|---|---|---|
| 生词本 | `hjy:vocab-book` | 复习主内容源；词条结构 `{ id, ko, rom, zh, pos?, exampleKo?, exampleZh?, addedAt, mastered }`（与单词学习页生词本为同一份数据，读取时归一化字段） |
| 系统词库 | `src/data/words.ts` | 生词本不足时补足一组 |
| 句子库 | `src/data/sentences.ts` + 首页每日一句收藏 | 拼写句子题 / 发音复习内容 |
| 复习偏好 | `hjy:review-prefs` | `{ groupSize: 10, mode: 'flashcard' }`（groupSize 与用户中心「复习节奏」设置互通，同一 key） |
| 复习结果 | `hjy:review-history` | 数组，每条 `{ date, mode, total, remembered, forgot, durationSec }`；写入后调用既有同步接口（失败静默，标注 `pending: true` 待重试） |
| 今日复习计数 | `hjy:review-daily` | 按日期重置，供页头 StatChip 与首页概览使用 |

**取词逻辑**: 优先取生词本中 `mastered: false` 的词；不足一组时用系统词库随机补足；生词本为空 → 空状态引导（见 Section 5）。「忘记了」的词在本轮末尾自动重排一次（仅重现一次，不循环）。

## Section 1 — 页头 + 模式切换

**布局（桌面 ≥1024px）**: 内容区最大宽 1120px 居中。左侧主标 30px 衬线「复习中心」+ 韩语副标「복습하기」+ 说明 16px 暖灰褐：「把收藏的词和句子再过一遍——记不住的，我们再来一次。」右侧 StatChip：「今日已复习 12 词 · 连续 5 天 🔥」。
**移动端 (<1024px)**: 主标降档 24px，说明文案省略，StatChip 收进标题下方一行横滚。

**模式切换（分段控制器）**: 页头下方居中 pill 三段切换，复用 design.md 分段控制器样式：
- **🃏 闪卡复习 | ✍️ 拼写练习 | 🎙 发音复习**
- 容器 `bg-sand` 圆角 pill 内边距 4px；激活段 `bg-paper` 白底 + 赤陶橘文字 + `shadow-card`，滑块用 Framer Motion `layoutId` 过渡（250ms, easeOutQuint）。
- 移动端：三段等宽全宽，图标 + 短文案（「闪卡 / 拼写 / 发音」），激活段图标上跳微动效（translateY -2px, spring）。
- 切换时记住上次选择（写入 `hjy:review-prefs.mode`），下次进页直接恢复。

**Animation**: 页头标题词级上移 24px 淡入 stagger 0.08s（400–700ms, easeOutQuint）；切换模式时内容区交叉淡入 + 上移 12px（250ms），列表/卡片重新 stagger。

## Section 2 — 闪卡复习模式

### 2.1 组进度条
- 顶部细进度条（3px，轨道 `bg-sand`，填充赤陶橘，宽度动画 300ms）：「第 2 组 · 本组 3/10」+ 右侧小字「本轮共 28 词」。
- 分组大小读取 `hjy:review-prefs.groupSize`（默认 10，3–50，用户中心可改）。

### 2.2 卡片舞台
**布局**: 居中主舞台，复用 WordCard 3D 翻面范式。大卡 480×320px（移动端全宽 × 300px），透视 1200px：
- **正面（默认态，隐藏释义）**: 来源小标签（蜂蜜金胶囊，「生词本」/「词库 · 食物」/「每日一句」）+ 韩语词 Serif KR 40px 居中 + 中央 SpeakButton（lg，点击播音不翻面）+ 底部浅褐小字提示「点击卡片查看释义」。
- **背面**: 罗马音 16px 浅褐 + 中文释义 24px 墨褐 + 词性标签 + 例句（若有，韩语 + 小喇叭）。
- **重现标记**: 本轮「忘记了」重排的卡，左上角陶红小缎带「再来一次」。

**Animation**: 翻面 rotateY 0→180°（600ms, easeOutQuint），背面从 -180° 归位；判词后卡片横向滑出 40px 淡出、新卡从对侧滑入（280ms）。

### 2.3 判定按钮（翻面后显示）
- 卡片下方两个大按钮并排（移动端全宽两行改为左右各 50%）：
  - **「✗ 忘记了」**: 陶红描边 pill（hover 底色 `accent-terracotta-soft` 偏红），快捷键 ←。
  - **「✓ 记住了」**: 橄榄绿实底白字 pill，快捷键 →。
- 按钮未翻面时置灰禁用（透明度 40%），翻面后启用并弹入（scale 0.9→1, 200ms）。
- 点击「记住了」：卡片右上角飘橄榄绿 +1 动画；点击「忘记了」：卡片轻震（translateX ±6px, 300ms）后滑出，该词入本轮末尾重现队列，同时把该词在 `hjy:vocab-book` 中 `mastered` 置 false。

### 2.4 组末小结（庆祝态）
- 一组完成后，舞台卡片替换为小结卡（同尺寸纸白卡，24px 圆角）：
  - 顶部庆祝动效：蜂蜜金小纸屑/星点从卡片中心扩散（12 个粒子，随机方向 60–120px，opacity 1→0，800ms，仅一次非循环）。
  - 大数字：「本组 记住 8 · 忘记 2」，比例用橄榄绿/陶红双色迷你条形（div 宽度动画 500ms）。
  - 文案：全记住时「太棒了，全组通关！🎉」；有遗忘时「忘记的几张已排到队尾，再见面一次吧。」
  - 按钮：「进入下一组 →」（赤陶橘实底）+「结束本轮」（描边）。
- 全部组完成：总结卡「本轮共复习 28 词，记住率 86%」+ 结果写入 `hjy:review-history` 并尝试同步后端 + Toast「复习记录已保存」。

## Section 3 — 拼写练习模式

### 3.1 题型与出题
- **单词题**: 显示中文释义 + 词性（如「你好 · 感叹词」），输入韩语拼写。
- **句子题**: 显示中文句意（如「你吃饭了吗？」），输入整句韩语；下方给提示行：「首字母：ㅂ · 共 7 字」（长度按音节块计）。
- 单词/句子混合随机出题，比例约 7:3；题目来源同 Section 1 取词逻辑 + 句子库，按相同 groupSize 分组。

### 3.2 答题卡
**布局**: 居中卡片 640px 宽（移动端全宽），纸白 24px 圆角：
- 顶部：题型标签（蜂蜜金「单词拼写」/ 橄榄绿「句子拼写」）+ 进度「4/10」。
- 题干：中文 24px 衬线居中；句子题附提示行 14px 浅褐。
- 输入框：大号居中输入框（韩语 Sans KR 28px，底部 2px 赤陶橘下划线风格，focus 下划线加粗至 3px 动画 200ms），`placeholder="输入韩语…"`；自动聚焦，Enter 提交。
- **实时判定**: 输入时逐字符与答案比对——逐格显示在输入框上方（每个音节块一格 32×40px 小方格）：
  - 正确格：橄榄绿描边 + 绿字；
  - 错误格：陶红描边 + 红字，格子上方小箭头指示差异；
  - 未输入格：`border-warm` 虚线。
- **提交后**: 全部正确 → 整卡淡闪橄榄绿边 + 「完全正确！🎉」+ 自动播放 TTS；有误 → 显示正确答案行（韩语 28px 赤陶橘 + SpeakButton），错误格保持红色高亮对比，按钮变为「继续 →」。
- 底部辅助行：「🔊 听音提示」（播放 TTS，每题限用不限制但记录）、「跳过」（计入「忘记了」并末位重现一次）。

**Animation**: 切题时题干下移 16px 淡入（250ms）；逐格高亮随输入即时切换（100ms）；答对时格子做依次弹跳（stagger 0.04s, translateY -4px spring）；答错时输入框轻震（同闪卡）。

### 3.3 组末小结
- 同 2.4 小结卡范式，文案改为「本组拼对 7 / 10」，错误题列出最多 3 条「待巩固」清单（韩语 + 中文 + 小喇叭），点击可一键「加入生词本」（写入 `hjy:vocab-book`）。

## Section 4 — 发音复习模式

**复用发音练习页（pronunciation.md）Section 3 练习卡片组件**，本页仅做内容源与框架差异：

- **内容源**: 已学句子（发音练习页 `pron-done` 已标记的句子）+ 生词本词（单词也生成练习卡，句子区只显示单词 + 罗马音 + 中文，无序号）；每日一句收藏的句子并入。混排为一组（同 groupSize）。
- **页面结构**: 页头 Tab 下直接为纵向练习卡列表 + 顶部组进度条；每张卡完整保留：常速范读 / 慢速 0.6× / 跟读录音 / 回放 / 对比播放「范读→我」；「标记已练」改为「本轮通过 ✓」（橄榄绿 toggle）。
- 麦克风权限拒绝：Toast「需要麦克风权限才能跟读哦」，录音钮禁用，范读/慢速不受影响。
- **组末小结**: 「本组跟读 10 条 · 通过 8」，未通过的 2 条列出并附「再练一次」按钮（滚动回对应卡片并高亮脉冲两次）；结果写入 `hjy:review-history`（mode: 'pronunciation'）。

**Animation**: 卡片进入视口 stagger 0.07s 上移 24px；录音中按钮陶红脉冲 + 外圈波纹 1.2s 循环（同发音练习页）；「本轮通过」缎带 rotate 45° 滑入（spring）。

## Section 5 — 状态设计

| 状态 | 表现 |
|---|---|
| **空状态（生词本空 + 无已学句）** | 闪卡/拼写 Tab：`/empty-vocab.svg` 插画 + 「生词本还是空的，先去学几个词吧。」+ CTA「去单词学习 →」（赤陶橘实底，跳转 `/vocabulary`）；发音 Tab：「还没有练过的句子。」+「去发音练习 →」。空状态入场：插画 scale 0.9→1 + 上移 20px 淡入（400ms）。 |
| **加载** | 取词/组卷时舞台显示骨架卡（`bg-sand` 脉冲呼吸 1.2s），≤300ms 不显示。 |
| **同步失败** | 结果永远先写 localStorage；同步接口失败时 Toast「已保存在本机，联网后自动同步」（蜂蜜金图标），历史记录标 `pending: true`，下次进页静默重试。 |
| **TTS 不支持** | 所有 SpeakButton 降级禁用 + 一次性 Toast「当前浏览器不支持韩语语音朗读」。 |

## 移动端适配

- 底部 Tab Bar 不遮挡判定按钮：闪卡判定按钮区 `padding-bottom: env(safe-area-inset-bottom)`。
- 闪卡支持手势：翻面点击 / 判词左右滑（Framer Motion drag x，阈值 80px——右滑「记住了」、左滑「忘记了」，拖动时卡片随动旋转 ±4° 并浮现绿/红印章式标签）。
- 拼写输入框聚焦时页面上推避免键盘遮挡（`visualViewport` 监听）；逐字格横排溢出时自动换行。
- 发音复习录音大圆钮居中突出（同发音练习页移动端规范）。

## 令牌对应速查

背景 `bg-base` / 卡片 `bg-paper`+`shadow-card` / 分区 `bg-sand`；主按钮与进度 `accent-terracotta`，「记住了」与正确高亮 `accent-olive`，「忘记了」与错误高亮 `accent-clay-red`，来源标签与庆祝粒子 `accent-honey`；描边 `border-warm`；动效曲线 `cubic-bezier(0.22,1,0.36,1)`，同视口动效元素 ≤8。
