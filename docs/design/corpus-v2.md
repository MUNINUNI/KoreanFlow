# 语料中心联动改造 (Corpus v2 — 增量设计)

**基础**: 在现有 `corpus.md` 语料中心页之上增量，视觉与组件全部沿用现有语料页风格；本文档仅定义**新增**的按钮、气泡操作与进度反馈。原有布局/交互不变。

**目标**: 打通「语料 → 学习」的闭环——划词气泡可把词加入单词学习、把句子加入发音练习；语料卡片可一键批量提取词汇/句子到学习库。

---

## 变更 1 — 划词翻译气泡增加两个操作按钮

**位置**: 练习工作台 PDF/文本阅读模式（corpus.md Section 3c）的选词翻译气泡内。

### 1.1 气泡结构（改造后）

气泡保持现有样式（纸白 12px 圆角 + 小三角 + `shadow-lift`），内容自上而下：
1. 韩语词 20px 衬线 + 罗马音 + 中文释义 + 小喇叭（原有）。
2. **新增操作行**（分隔线 1px `border-warm` 之上是释义区，之下是操作区）——三个小号描边 pill 按钮横排（移动端等宽三列，气泡最小宽扩至 260px）：
   - **「☆ 加入生词本」**（原有按钮移入此行，样式统一）：写入生词本 `hjy:vocab-book`。
   - **「📖 加入单词学习」**: 把该词加入单词学习队列/词库——词条 `{ ko, rom, zh, pos, source: 'corpus', sourceId: <语料id>, addedAt }` 写入 `hjy:vocab-book`（与生词本同库，以 `source` 字段区分来源）；同时把该词标记进单词学习页「学习模式」的待学队列（`vocab-progress` 中置为新词）。
   - **「🎙 加入发音练习」**: 把**该词所在的整句**（从阅读文本中取选区所在句子边界）加入发音练习材料：`{ id, level: 'corpus', ko: <整句>, rom: '', zh: '', sourceId: <语料id> }` 写入 localStorage `hjy:pron-custom`；发音练习页与复习页发音模式读取该 key 合并进句子列表，标记蜂蜜金来源标签「语料」。
3. 词典未命中态（原有「本地词典未收录」）：三个按钮仍可用——「加入单词学习」时释义字段留空待用户在学习页补全；按钮上方保留「试试整句 TTS 朗读」。

### 1.2 交互与反馈

- 按钮点击后：图标对勾化 + 文案变为「已加入 ✓」（橄榄绿），按钮禁用防重复；气泡外弹 Toast「已加入单词学习」/「已加入发音练习」（底部胶囊，2.5s 自动消失，复用 Toast 组件）。
- 重复添加（词/句已在库）：按钮直接显示「已在库 ✓」置灰态。
- 点击行为不关闭气泡（用户可能连续点两个按钮）；Esc / 点空白处关闭逻辑不变。

**Animation**: 气泡弹出动画不变（scale 0.85→1 + 上移 6px 淡入 180ms）；按钮点击对勾 scale 0→1 spring + 按钮底色 100ms 内由纸白过渡到 `accent-olive` 10% 浅底；Toast 复用全局弹入动画。

## 变更 2 — 语料卡片「提取到学习库」操作

**位置**: 语料库列表（corpus.md Section 2）每张语料卡。

### 2.1 入口

- 卡片底部操作行在「打开练习 →」左侧**新增次要按钮「⚡ 提取到学习库」**（描边 pill，图标赤陶橘）；同时收入 ⋯ 菜单作为第二项。
- **适用类型**: 📄 PDF 与 📝 文本语料可用；🎧 音频 / 🎬 视频卡该按钮置灰 + hover tooltip「音视频语料暂不支持文本提取」。
- 无文本层的扫描版 PDF：点击后 Toast「这份 PDF 没有可提取的文字层」（蜂蜜金提示），不进入流程。

### 2.2 提取流程（Modal）

点击后弹出 Modal（纸白 24px 圆角 + 暖色遮罩，复用 Modal 组件；移动端底部抽屉上滑）：

- **标题**: 「提取到学习库 · 《语料名》」
- **内容区**: 两个勾选项（默认全选，橄榄绿对勾 checkbox）：
  1. ☑ **提取词汇到单词学习库** —— 说明「用本地词典匹配文中韩语词，去重后加入」
  2. ☑ **提取句子到发音练习库** —— 说明「按句号/问号/换行切分，过滤超长句（>40 字）」
- **执行**: 主按钮「开始提取」（赤陶橘实底）。点击后按钮变加载态（spinner +「提取中…」），Modal 内容区切换为**进度反馈**：
  - 进度条（3px 赤陶橘，宽度动画）+ 实时状态文字滚动：「正在分词… → 词典匹配中 (156/420)… → 去重… → 写入学习库…」。
  - 提取为纯本地计算（本地词典 `dictionary.ts` 匹配），无网络依赖；大文本（>5 万字）分片处理避免卡顿，进度条真实反映进度。
- **完成态**: Modal 切换为结果卡：
  - 橄榄绿大对勾（scale 0→1 spring 弹入）+ 「提取完成！」
  - 两行结果统计：「📖 新增 23 个词到单词学习（跳过已在库 41 个）」「🎙 新增 15 个句子到发音练习」；未匹配词过多时附一行浅褐小字「有 N 个词本地词典未收录，已按原文保存」。
  - 按钮：「去学习 →」（赤陶橘实底，跳 `/vocabulary`）/「完成」（描边，关闭 Modal）。
  - 全部词条已在库（0 新增）时：蜂蜜金提示「没有新内容——这份语料的词你都收过了」，按钮只留「完成」。

### 2.3 数据写入

| 目标 | Key | 结构 |
|---|---|---|
| 单词学习库 | `hjy:vocab-book` | 追加词条，`source: 'corpus'`，`sourceId` 记录语料；按 `ko` 字段去重 |
| 发音练习库 | `hjy:pron-custom` | 追加句子 `{ id, level: 'corpus', ko, sourceId }`；按 `ko` 去重 |
| 提取记录 | `hjy:corpus-extract-log` | `{ corpusId, date, wordsAdded, sentencesAdded }`，供语料卡显示「已于 8/11 提取过」小标签 |

- 已提取过的语料卡：「提取到学习库」按钮旁显示 12px 浅褐小字「上次提取：+23 词 +15 句」；再次点击仍可执行（增量去重，只加新内容）。

**Animation**: Modal 上滑 24px + 遮罩淡入（250ms）；进度状态文字逐行上入替换（200ms 交叉淡入）；结果对勾 spring 弹入（scale 0→1.1→1, 400ms）+ 两行统计 stagger 0.08s 上移 12px 淡入；语料卡「上次提取」标签淡入（200ms）。

## 状态与边界

| 状态 | 表现 |
|---|---|
| **生词本/发音库首次写入** | key 不存在时自动初始化空数组，无需用户干预。 |
| **存储超限** | localStorage 写入抛错时 Toast「本机存储空间不足，请先导出备份再清理」（陶红）。 |
| **音视频语料** | 提取按钮置灰 + tooltip 说明（见 2.1）。 |
| **提取中断（关页/刷新）** | 分片写入、每片落盘；中断后已提取部分保留，语料卡显示「部分提取」标签，再次提取自动去重续传。 |
| **气泡定位** | 新增按钮加宽气泡后，左右钳制逻辑不变（距屏边 ≥8px），三角指针随选区偏移重新对位。 |

## 移动端适配

- 气泡操作行三按钮等宽，文案缩写为「生词本 / 学单词 / 练发音」+ 图标；气泡全宽时贴屏边 8px。
- 提取 Modal 为底部抽屉（上滑入场 300ms，可下滑关闭）；进度与结果态同桌面。
- 语料卡操作行空间不足时，「提取到学习库」收进 ⋯ 菜单首位。

## 令牌对应速查

新增按钮统一沿用语料页 pill 规范：主操作 `accent-terracotta`，成功反馈 `accent-olive`，提示/警告 `accent-honey`，危险 `accent-clay-red`；气泡/Modal `bg-paper` + `shadow-lift` + 遮罩 `rgba(46,42,38,0.4)`；来源标签 `accent-honey` 描边胶囊；动效曲线 `cubic-bezier(0.22,1,0.36,1)`，反馈 150–250ms。
